TIERED SECURITY CONSENSUS FOR ALL TEN BUILDS
Tier 1: authenticated device/session, immutable tenant and role authorization, RLS, bounded access tokens, deny by default.
Tier 2: independently enrolled asymmetric issuer keys and exact signed issuer/audience/scope, source revision, key pin and 24-hour freshness; key rotation/grace/expiry with revocation.
Tier 3: durable replay/idempotency, custody ledger, independent second witness, source hash and branch provenance, audit nonrepudiation.
Tier 4: owner/supervisor consent, finance and customer delivery authority, source-only vs Master CONNECTED separation, privileged command gate.
Tier 5: cross-device/offline protection, retention/privacy, security monitoring, signed backup/restore and disaster-recovery acceptance.
