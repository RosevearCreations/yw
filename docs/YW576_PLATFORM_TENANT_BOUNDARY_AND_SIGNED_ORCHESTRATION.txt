PLATFORM (YW main Shell / Sysop)
- Verified curated membership via original ywi_is_platform_administrator_489 RPC is necessary. Ree/Jack individual accounts are eligible only when enrolled; user display name or company owner is not permission.
- Show company directory and aggregate module counts, platform health/readiness, onboarding requests, subscription administration and per-tenant feature flags only after real server-authorized source enrollment. NO jobs, employee names, payroll, invoices, margins, customer addresses, service properties or full company operation records on Sysop.
- New company sites require a separate privileged provisioning endpoint that verifies Sysop membership on server, reserves tenant ID/domain, assigns owner, provisions scoped RLS and roles, chooses subscription with verified payment-provider state, creates company-specific public site and records audit + rollback. YW576 offers a client-side draft for review, not a real DB write or paid subscription.
- Company site manager should later include tenant status, active modules, quota/usage, subscription aging, help desk, incident acknowledgements, and anonymized health signals. Never proxy arbitrary company record access.
- Main/platform view hides company navigation and private panels. Client-only visual isolation is not server authorization; all tenant originals still enforce RLS and owner grants.

SIGNED BOOKING / QUOTE / JOB / CREW / ROUTE
- Canonical implementation order from YW552–555 originals is approved booking, actually customer-accepted original quote, original canonical Job, verified crew Dispatch, then workability and route recheck. Skipping actual Job creation to send a crew violates source custody.
- scripts/yw576-signed-route.mjs is a source-only P-256 verifier; each stage requires independently server-verified matching source, enrollment key/capability, tenant/customer/property identity, revision, time window, nonce and previous-source SHA256.
- No original provider JWT/DB signing is forged in this build. The script cannot make records original and does not send notifications, create Jobs, assign employees or take payment. It reports verified SHAPE only when the supplied trusted originals are verified.

Rosevear Comms Hub sends messages only after verified owner/recipient consent, signed outbox and actual durable ACK. 1.0 peers remain compatible with additive 1.1; unrelated app updates do not require all seven apps to deploy.
