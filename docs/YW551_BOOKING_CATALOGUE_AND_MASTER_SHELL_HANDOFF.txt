# Yard Workers 551 — Landscaping Booking Catalogue & Master Shell Handoff

## Company workspace and scope

- **Source identity:** `yw` — Yard Workers platform-level source, repository `RosevearCreations/yw`.
- **Platform shell:** Ree/Jack Sysop monitoring, identity, security, releases and integration authority; never a landscaping-company tenant.
- **Company workspace:** e.g. **Rosevear Landscaping**, owned and separated by `ywi_companies.id` and server-side RLS.
- **YW 551:** Company owners maintain landscaping services, add-ons, disposal/dump fees, price units, and spring/summer/fall/winter overrides in Settings. The season-specific preview gives a CAD pre-tax *illustration* only.
- **Non-goals:** No actual booking submission, slot allocation, invoice, card charge, waste-hauling manifest, licensed-disposal assertion or historical-job mutation. None may be inferred from a catalogue row or preview.

## Data and security

1. Deploy additive, reviewed [`sql/company_booking_catalogue_551.sql`](../sql/company_booking_catalogue_551.sql) **after** `company_service_offering_registry_420.sql`; this repository file alone does not prove live installation.
2. The table `ywi_company_booking_catalogue_551` stores per-company identifiers, draft/active state, price units, integer CAD cents, optional seasonal overrides and owner edit attribution. The `ywi_company_booking_catalogue_audit_551` records append-only create/update snapshots.
3. Database grants and RLS restrict read/create/update to the authenticated owner of the same company. `company_id`, code, type and item identity are immutable after creation. Client UI rechecks authenticated owner; server RLS remains definitive.
4. A company's `landscape` offering must be enabled in the independent service registry before the preview is considered potentially bookable. The catalogue does **not** bypass Build 421's separate new-work authorization.
5. Disabled rows remain owner drafts; no public/anonymous read grants. A later customer-facing booking API must provide a carefully scoped public view and enforce server-side price/availability/booking confirmation.
6. Fee labels are estimates only, not environmental-compliance proof. Actual disposal manifests, site authorization, invoices and receipts remain governed by separate modules and evidence.
